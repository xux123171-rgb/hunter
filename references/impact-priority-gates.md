# 影响 & 优先级 & 合规门（熔自 AI-Bug-Bounty / OpenSwarm / bug-reaper）

## 一、影响框架：按"链路能到达的最坏结果"定价
> 洞的价值不由入口决定，由**它最远能推到哪**决定。阶段4 出每个 primitive 后，先问一句"这往哪推？"，定级按终点不按入口。

- 未授权接口 → 能拖库吗？能 RCE 吗？能读他人 PII 吗？（终点=数据外泄/接管 → 严重）
- SSRF → 能读 169.254 云元数据 → 拿 cloud 权限（终点=云接管 → 严重）
- 存储 XSS → 能偷 cookie → ATO（账号接管）（终点=ATO → 高）
- SQL 盲注 → 能拖整库 / 能写文件（终点=拖库 → 严重）
- 越权 IDOR → 只读 vs 能改/删（读=中低，改/删=高）

**规则**：报前把"最远可达点"写进 finding 的"影响"字段；定级按最远可达点，不按入口。

## 二、合规硬限（比"payload 克制"更量化，写进每个 scope）
- **限速**：手动 ≤2 req/s/host；fuzzing/scanning/brute-force **需用户明确放行**（默认 10 rps 是上限不是常态）。
- **不外泄**：证明影响用"读"，不拖全库；PII 证据只取**首行并打码**，不下载/不留存。
- **不落点不横移**：finding 停在发现它的 host 上，不写持久化、不 pivot 内网（除非授权 + 红线允许）。
- **零破坏**：禁 DoS/耗尽资源/改数据。
- **closed allowlist**：每个请求前过 scope，越界=停。

## 三、divergent hypotheses → primitive → finding（阶段4 的推理骨架）
对每个端点先**发散假设**（它可能有哪些洞型，不限一种），再逐一试出 **primitive**（可控原语：一条可回显/可延迟/可读的注入点），再把 primitive **构造成 impact**（最远可达点）。
- primitive = "我能控制这个参数且它真进了下游"
- impact = "控制它能触发的最坏事"
- 只有 primitive 坐实才往上推；primitive 都坐不实 → 该端点判死。

## 四、false-positive-elimination（阶段5 的攻击性排误报，独立一步）
在 7 问之前，先做激进的误报排除（熔自 bug-reaper）：
1. **追全路径**：从入口参数到 sink，标出每一个 校验/编码/过滤/WAF 点。
2. **每个防御点都要过**：任一环节挡住 → 该洞降为"被缓解"，不算。
3. **对照组是硬要求**：合法值 vs payload 的响应**必须 diff 出差异**；无差异=误报。
4. **区分"设计如此"**：CDN 缓存掩盖、公开素材、`/plugins` 返 401 等=不是洞。
5. **激进重估**：假设它是误报，看能不能自证；自证不了就砍或降级。

## 五、哪类洞真给钱（patterns，来自 ~14.8k HackerOne 报告的量级）
> 用于排"值不值得磕"，严重→低的顺序已含在 SOP 阶段4。

| 类 | 量级(参考中位) | 备注 |
|---|---|---|
| 命令注入 / RCE | 最高 | 出实锤直接严重 |
| HTTP 请求走私 | 高 | 需 WAF/网关边界 |
| Auth / OAuth/SAML → ATO | 高(顶 $35k) | 需 2 账号 |
| SSRF→云元数据→RCE | 中高 | 云托管才值钱 |
| 业务逻辑 / race | 中(扫描器盲) | 手打才有 |
| 越权 IDOR/BOLA | 中(可顶高) | 需 2 可用账号 |
| 存储 XSS→ATO | 中 | 链路推 ATO |

公益 SRC（补天）不看现金，看"能不能出可复现实锤"——上面"出实锤率 + 零登录态"权重 > 现金权重。

## 六、阶段门（进下一阶段的前置条件，OpenSwarm 式）
- **0→1**：scope.md 有 授权范围逐字 + 红线 + 限额
- **1→2**：assets.md 有 ≥1 个活子域/IP（否则全目标判死候选）
- **2→3**：probe.md 有 ≥1 个"活且有面"资产（全死→写 deadlines 收口）
- **3→4**：endpoints.md 有 ≥1 个"可枚举 ID 或无鉴权"端点
- **4→5**：finding 有 raw 请求/响应 证据（无证据不算 confirmed）
- **5→6**：7 问全过 + FP-elimination 通过 → 才出报告
- 任一门不过 → 停在该阶段，写 journal 说明，不硬推。
