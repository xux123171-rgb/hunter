# 补天/漏洞盒子 报告模板（可复制纯文本，逐字段框起来）

> 用法：出洞后把下面各块复制进平台表单。`__` 处填目标实际值。
> 归属信息逐字核对页脚 ICP/备案号原文再填，不脑补。

## 平台 A — 补天公益（积分制）
```
【漏洞类型】__未授权访问/SQL注入/越权/信息泄露__
【漏洞URL】__https://子域/路径__
【风险等级】__严重/高危/中危__
【漏洞简要描述】__一句话说清：哪个接口/路径 + 什么问题 + 能造成什么影响__

【漏洞详细细节】
1、复现过程与影响范围：
__步骤化：前置条件 → 操作 → 响应。影响写具体场景（如"可枚举全部 1.4 万账号"），不写空话。__
2、截图位置：__1_归属_首页 / 2_归属_证据位置 / 3_复现_xxx__
3、利用组件：__curl 即可 / 需浏览器 / 需2个账号__
4、PoC：
__代码块，payload 克制（sleep 1 / 回显1行 / 读1行表）__

【危害】__数据泄露/未授权操作/可进一步利用__
【修复建议】__可执行：加鉴权/改参数化查询/统一响应/加防火墙规则，不写空话__
```
